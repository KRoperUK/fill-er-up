# fill-er-up — retired ⛽️

> **This project is archived.** The UK fuel-price data it used to scrape and
> publish now comes straight from the official government scheme, and the
> consumer-facing successor is a native iOS app.

## Looking for UK fuel-price data?

Use the official source — the **DfT Fuel Finder** developer portal:

### 👉 https://www.developer.fuel-finder.service.gov.uk/

It's the UK government's open fuel-price scheme (Open Government Licence v3.0):
live forecourt prices and station details via API, CSV download, or email — the
sanctioned replacement for everything this repo used to do.

## 📱 Coming soon: **Fill 'er Up** for iOS

The successor to this project is **Fill 'er Up**, a free iOS app that helps UK
drivers find the cheapest petrol and diesel nearby — powered by the official Fuel
Finder data:

- ⛽️ Live forecourt prices, ranked by **price** or **distance**
- 💷 **Cost-to-fill** and savings-vs-average estimates
- 🗺️ List & map views, a home-screen **widget**, **Siri** and **CarPlay**
- 🚗 A **Garage**: tax & MOT status, full MOT history, and expiry reminders

**Launching soon on the App Store.** Watch this space.
